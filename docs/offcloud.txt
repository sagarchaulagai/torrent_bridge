API Documentation

Build integrations with the offcloud API. Manage networks, nodes, and edge servers programmatically.
Creating API Keys

Create API keys in your dashboard under Settings → Access → New API Key.

⚠️ Important: API keys are shown only once after creation. Store them securely in your environment variables.
env

OFFCLOUD_API_KEY=ock_live_xxxxxxxxxxxxxxxxxxx

Authentication

All API requests require authentication using a Bearer token in the Authorization header.
Base URL
https://api.offcloud.me/v1
bash

curl https://api.offcloud.me/v1/networks \
  -H "Authorization: Bearer YOUR_API_KEY"

Error Handling

The API returns standard HTTP status codes and JSON error responses.
200
Success
201
Created
400
Bad Request (validation error)
401
Unauthorized (invalid/missing API key)
403
Forbidden (insufficient permissions)
404
Not Found
500
Internal Server Error
json

{
  "detail": "Error message here"
}

Webhooks
Overview

Receive real-time notifications when events occur in your organization. Configure webhooks in Settings → Integrations → New Webhook.
Payload Format
json

{
  "event": "node.connected",
  "timestamp": "2026-01-06T19:00:00Z",
  "org_id": "uuid",
  "data": {
    "node_id": "uuid",
    "node_name": "laptop-001",
    "network_id": "uuid",
    "network_name": "My Network",
    "previous_status": "offline",
    "new_status": "healthy",
    "reason": "handshake_active"
  }
}

Webhook Headers

Every webhook request includes these headers:
X-Offcloud-Signature
Signature for verification (format: t=timestamp,v1=hash)
X-Offcloud-Event
The event type (e.g., node.connected)
X-Offcloud-Delivery
Unique delivery ID (UUID)
Content-Type
application/json
User-Agent
Offcloud-Webhooks/1.0
Signature Verification

Every webhook request includes a signature header for verification:
text

X-Offcloud-Signature: t=1234567890,v1=sha256-hash

Verification Example (Node.js)
javascript

const crypto = require('crypto');

function verifySignature(payload, signature, secret) {
  const parts = signature.split(',');
  const timestamp = parts[0].split('=')[1];
  const hash = parts[1].split('=')[1];
  
  const signedPayload = `${timestamp}.${payload}`;
  const expected = crypto
    .createHmac('sha256', secret)
    .update(signedPayload)
    .digest('hex');
  
  return crypto.timingSafeEqual(
    Buffer.from(hash),
    Buffer.from(expected)
  );
}
